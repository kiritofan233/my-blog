# 数据结构笔记

## 一、复杂度与算法分析

### 1. 时间复杂度

时间复杂度衡量输入规模增大时，基本操作次数如何增长。常见量级：

$$
1<\log n<n<n\log n<n^2<n^3<2^n<n!.
$$

$O$ 给出渐近上界，$\Omega$ 给出下界，$\Theta$ 给出同阶界。教材和面试常把 $O(n)$ 当作简写，但严格地说，若明确知道增长阶为线性，写 $\Theta(n)$ 更准确。

连续执行的两段程序把开销相加，嵌套循环按实际执行次数相乘或求和，不是见到两层循环就写 $O(n^2)$。

```cpp
for (int i = 1; i < n; i *= 2) {
    // 常数时间操作
}
```

执行约 $\log_2n$ 次，时间复杂度为 $O(\log n)$。实际程序还要防止整数乘二溢出。

```cpp
for (int i = 0; i < n; ++i)
    for (int j = 0; j < i; ++j) {
        // 常数时间操作
    }
```

总次数为 $0+1+\cdots+(n-1)=n(n-1)/2$，因此是 $\Theta(n^2)$。

### 2. 最坏、平均和均摊

- 最坏复杂度：规模固定时，最不利输入需要多少操作。
- 平均复杂度：在明确的输入概率模型下，对操作次数取期望。
- 均摊复杂度：把一串操作的总成本平均到每次操作上，不要求输入是随机的。

动态数组按倍数扩容时，某次追加可能需要搬移全部元素，耗时 $O(n)$；但连续 $n$ 次追加的总成本为 $O(n)$，所以单次追加的均摊复杂度是 $O(1)$。

### 3. 空间复杂度与递归

辅助空间一般不计输入本身，但要明确是否包含输出和递归栈。递归算法只看局部变量会漏算调用栈。

常见递推关系：

| 递推关系            | 时间复杂度   |
| ------------------- | ------------ |
| $T(n)=T(n-1)+O(1)$  | $O(n)$       |
| $T(n)=T(n/2)+O(1)$  | $O(\log n)$  |
| $T(n)=T(n/2)+O(n)$  | $O(n)$       |
| $T(n)=2T(n/2)+O(n)$ | $O(n\log n)$ |

第三行是几何级数 $n+n/2+n/4+\cdots$，不是 $n\log n$。

## 二、线性表

### 1. 顺序表

顺序表用连续空间存元素，通过下标可以直接算出地址，所以随机访问为 $O(1)$。

| 操作             | 时间复杂度  | 原因             |
| ---------------- | ----------- | ---------------- |
| 按下标读写       | $O(1)$      | 地址可直接计算   |
| 无序表按值查找   | $O(n)$      | 可能扫描全部元素 |
| 中间插入或删除   | $O(n)$      | 需要搬移后续元素 |
| 动态数组尾部追加 | 均摊 $O(1)$ | 偶尔扩容搬移     |
| 删除最后一个元素 | $O(1)$      | 通常只调整长度   |

顺序表容量与当前长度不同。插入前检查容量，访问前检查下标是否在有效长度内。

C++ 的 `vector` 扩容可能使已有的指针、引用和迭代器失效；中间插入或删除也会影响操作位置及之后的引用关系。

### 2. 单链表

节点保存数据和后继指针，物理位置不要求相邻。链表按位置查找为 $O(n)$，不能像数组一样随机访问。

```cpp
struct Node {
    int value;
    Node* next;
};

// p 必须指向一个有效节点。
void insert_after(Node* p, int value) {
    Node* q = new Node{value, p->next};
    p->next = q;
}

// 删除 p 的后继；p 本身不能被删除。
bool erase_after(Node* p) {
    if (p == nullptr || p->next == nullptr) return false;
    Node* q = p->next;
    p->next = q->next;
    delete q;
    return true;
}
```

插入时必须先保存原后继，再让前驱指向新节点。若直接覆盖原指针而未保存，后面的链就找不到了。

“链表删除是 $O(1)$”要补条件：单链表中已经知道待删节点的前驱时，修改链接是 $O(1)$；若还要查找前驱，整个操作可能是 $O(n)$。

带头节点的链表用一个不存业务数据的哑节点统一首部操作。头指针指向谁、空表怎样表示，要在实现开始时定清楚。

### 3. 反转链表

```cpp
Node* reverse_list(Node* head) {
    Node* prev = nullptr;
    Node* cur = head;
    while (cur != nullptr) {
        Node* next = cur->next; // 先保留还没有处理的部分
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}
```

这个版本假设 `head` 指向第一个数据节点，且链表无环。循环中，`prev` 指向已反转部分，`cur` 指向尚未反转部分的首节点。时间 $O(n)$，额外空间 $O(1)$。

### 4. 双向链表与循环链表

双向链表增加前驱指针，已知节点时可以直接向两侧修改链接，但每个节点多占一个指针空间，操作时也必须同时维护两侧关系。

循环链表最后一个节点指回首节点或头节点，适合循环访问。遍历终止条件应是“回到起点”，不能继续用 `nullptr` 判断结束。

带哑头节点的双向循环链表，空表时可约定 `head->next == head` 且 `head->prev == head`。这个约定能减少边界分支。

## 三、栈、队列与递归

### 1. 栈

后进先出，只在栈顶插入和删除。典型用途：函数调用、括号匹配、表达式求值、深度优先搜索、撤销操作。

括号匹配的规则：

1. 遇到左括号入栈。
2. 遇到右括号，先检查栈是否为空，再检查是否与栈顶匹配。
3. 匹配则弹栈，不匹配立即失败。
4. 扫描结束后栈为空才算全部匹配。

例如 `([{}])` 合法，`([)]` 不合法。只统计左右括号数量无法判断嵌套次序。

后缀表达式求值：遇操作数入栈；遇二元运算符，先弹出右操作数，再弹出左操作数。表达式 `8 3 -` 的结果是 $8-3$，顺序不能反。

### 2. 循环队列

队列先进先出，典型用途是任务排队和广度优先搜索。顺序队列若只让首尾下标向右移动，会出现前面有空位却不能继续入队的“假溢出”，循环队列通过取模复用空间。

约定：容量为 $M$ 的数组，`front` 指向队首，`rear` 指向下一个可写位置，留一个空位区分空与满。

$$
\text{空：front=rear},\qquad
\text{满：(rear+1)\bmod M=front},
$$

$$
\text{长度}=(rear-front+M)\bmod M.
$$

实际最多存 $M-1$ 个元素。若改为单独记录元素个数，就可以用满全部 $M$ 个位置，但判空、判满的规则也要一起改。

### 3. 单调栈与单调队列

单调栈常用于找“左边或右边第一个比当前元素大或小的元素”。例如求右侧第一个更大值的下标：

```cpp
std::vector<int> next_greater(const std::vector<int>& a) {
    int n = static_cast<int>(a.size());
    std::vector<int> answer(n, -1), st;
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && a[st.back()] < a[i]) {
            answer[st.back()] = i;
            st.pop_back();
        }
        st.push_back(i);
    }
    return answer;
}
```

每个下标最多入栈一次、出栈一次，因此总时间为 $O(n)$。代码中的严格小于对应“严格更大”；若题意包含相等，需要重新处理比较符号。

单调队列常用于固定窗口的最大值或最小值：队尾删除不可能成为答案的元素，队首删除已经过期的下标。保存下标比只保存数值更方便判断过期。

### 4. 递归写法

写递归必须说明终止条件、问题如何缩小、返回结果代表什么。函数能调用自己并不代表算法正确。

递归与显式栈常可互相转换。深度可能接近 $n$ 的链表或退化树问题，要留意调用栈溢出；改成循环有时更合适。

## 四、串与模式匹配

### 1. 朴素匹配

主串长 $n$，模式串长 $m$。从主串各个候选起点逐个比较，最坏时间 $O(nm)$。字符重复较多且常在末尾失配时，容易出现大量重复比较。

### 2. KMP 的前缀函数

KMP 利用模式串已经匹配部分的前后缀关系，失配时移动模式串状态，主串指针不后退。

约定 `pi[i]` 表示子串 `p[0..i]` 的最长相等真前缀与后缀长度。“真前缀”不能等于整个子串。

例如模式串 `ababaca`：

```text
下标： 0 1 2 3 4 5 6
字符： a b a b a c a
pi：   0 0 1 2 3 0 1
```

```cpp
std::vector<int> prefix_function(const std::string& p) {
    int m = static_cast<int>(p.size());
    std::vector<int> pi(m, 0);
    for (int i = 1; i < m; ++i) {
        int j = pi[i - 1];
        while (j > 0 && p[i] != p[j]) j = pi[j - 1];
        if (p[i] == p[j]) ++j;
        pi[i] = j;
    }
    return pi;
}

int kmp_find(const std::string& text, const std::string& p) {
    if (p.empty()) return 0;
    auto pi = prefix_function(p);
    int n = static_cast<int>(text.size());
    int m = static_cast<int>(p.size());
    int j = 0;
    for (int i = 0; i < n; ++i) {
        while (j > 0 && text[i] != p[j]) j = pi[j - 1];
        if (text[i] == p[j]) ++j;
        if (j == m) return i - m + 1;
    }
    return -1;
}
```

预处理 $O(m)$，匹配 $O(n)$，额外空间 $O(m)$。寻找全部匹配时，完整匹配后可令 `j = pi[j - 1]` 继续扫描，以保留重叠匹配。

教材中的 `next` 数组可能使用不同下标和初值约定。先看定义再比较数值，不要把 `next` 和这里的 `pi` 直接混用。以上示例用 `int` 下标，假定序列长度可由 `int` 表示。

## 五、树与二叉树

### 1. 基本概念

树是连通且无环的结构。含 $n$ 个节点的非空树有 $n-1$ 条边。

本笔记约定根节点深度为 $0$，树高为根到最深叶子的边数，单节点树高度为 $0$。有的教材把层数从 $1$ 开始，公式使用前要统一约定。

二叉树每个节点最多两个孩子，且左右有区别。普通树的“节点度”常指孩子数；无向图中的顶点度则指关联边数，两者语境不同。

对于非空二叉树，若度为 $0,1,2$ 的节点数分别为 $n_0,n_1,n_2$，则

$$
n_0=n_2+1.
$$

由边数一方面为 $n-1$，另一方面为 $n_1+2n_2$，两式相等即可得到。

高度为 $h$ 的二叉树最多有 $2^{h+1}-1$ 个节点。国内教材常将每层都达到最大节点数的树称为满二叉树；完全二叉树要求最后一层之前都满，最后一层节点从左向右连续排列。

### 2. 遍历

| 遍历 | 次序             | 常见用途                 |
| ---- | ---------------- | ------------------------ |
| 前序 | 根、左、右       | 复制结构、带空标记序列化 |
| 中序 | 左、根、右       | 二叉搜索树输出有序序列   |
| 后序 | 左、右、根       | 删除树、先算子树再合并   |
| 层序 | 从上到下逐层访问 | 最短层数、按层统计       |

递归遍历时间均为 $O(n)$，额外栈空间为 $O(h)$，最坏可达 $O(n)$。层序遍历用队列，额外空间取决于最大层宽，最坏为 $O(n)$。

节点值互不相同时，“前序 + 中序”或“后序 + 中序”可以唯一确定二叉树；“前序 + 后序”通常不能。若节点值重复，还需要额外信息消除歧义。

### 3. 二叉搜索树

先约定关键字不重复：左子树所有关键字小于根，右子树所有关键字大于根。重复值可以计数或按固定规则存放，但整个实现必须遵守同一约定。

查找、插入、删除均为 $O(h)$。普通二叉搜索树按有序数据依次插入可能退化成链表，此时为 $O(n)$，并不自动保证 $O(\log n)$。

删除分三类：

1. 叶子节点：直接断开。
2. 只有一个孩子：让父节点接到该孩子。
3. 有两个孩子：用中序前驱或后继替换，再删除对应节点。

中序后继是右子树中最小的节点，因此它没有左孩子，最终会归结为前两类。

### 4. AVL 树与红黑树

AVL 树要求每个节点左右子树高度差绝对值不超过 $1$。插入或删除后，自下而上更新高度，并用旋转恢复平衡。

| 失衡形态 | 常见修复                   |
| -------- | -------------------------- |
| LL       | 对失衡点右旋               |
| RR       | 对失衡点左旋               |
| LR       | 先左旋左孩子，再右旋失衡点 |
| RL       | 先右旋右孩子，再左旋失衡点 |

旋转必须保持二叉搜索树的中序顺序不变。AVL 删除后可能需要继续向上修复多个祖先。

红黑树通过颜色约束保证高度为 $O(\log n)$。常见约定包括根为黑色、空叶节点为黑色、红节点不能有红孩子、从一个节点到其后代空叶的各条路径黑节点数相同。它比 AVL 放宽了高度平衡要求，操作仍为对数时间。

### 5. 堆与优先队列

二叉堆在形状上是一棵完全二叉树。小根堆只要求父节点不大于孩子，并不要求兄弟或同层节点有序。

数组从 $0$ 开始编号：

$$
\operatorname{left}(i)=2i+1,\quad
\operatorname{right}(i)=2i+2,\quad
\operatorname{parent}(i)=\lfloor(i-1)/2\rfloor\ (i>0).
$$

- 查看堆顶：$O(1)$。
- 插入：先放末尾，再向上调整，$O(\log n)$。
- 删除堆顶：末尾元素补到根，再向下调整，$O(\log n)$。
- 从最后一个非叶节点开始向下调整建堆：$O(n)$。

建堆是线性时间，因为大多数节点靠近叶子，实际需要下沉的层数很少；逐个插入建堆的上界则为 $O(n\log n)$。

### 6. 哈夫曼树

每次取当前权值最小的两棵树合并，直到只剩一棵树。所得树使带权路径长度

$$
WPL=\sum_iw_i\ell_i
$$

最小，其中 $\ell_i$ 是第 $i$ 个叶子的深度。沿左、右分支分别记 $0,1$ 可得到前缀编码，任何一个符号的编码都不是另一个的前缀。

使用最小堆构建的时间为 $O(n\log n)$。权值相同时树形和编码不一定唯一，但最小带权路径长度相同。

## 六、图

### 1. 概念与存储

图记为 $G=(V,E)$。本节用 $V$、$E$ 也分别表示顶点数和边数，复杂度中的含义依上下文判断。

无向图中所有顶点度数之和为 $2E$；有向图中入度和、出度和都等于 $E$。

| 存储方式   | 空间     | 判断两点是否有边  | 遍历某点全部邻居 |
| ---------- | -------- | ----------------- | ---------------- |
| 邻接矩阵   | $O(V^2)$ | $O(1)$            | $O(V)$           |
| 普通邻接表 | $O(V+E)$ | 通常 $O(\deg(v))$ | $O(\deg(v))$     |

稠密图常用矩阵，稀疏图常用邻接表。无向边通常在邻接表中存两次，但空间阶仍为 $O(V+E)$。有权图不能随意用权值 $0$ 表示“无边”，因为零权边也可能合法。

### 2. BFS 与 DFS

BFS 按层扩展，用队列；DFS 沿一条路径深入，用递归或显式栈。在邻接表上，两者完整遍历都为 $O(V+E)$；邻接矩阵上通常为 $O(V^2)$。

```cpp
std::vector<int> bfs_distance(
    const std::vector<std::vector<int>>& adj, int source) {
    int n = static_cast<int>(adj.size());
    std::vector<int> dist(n, -1);
    if (source < 0 || source >= n) return dist;
    std::queue<int> q;
    dist[source] = 0;
    q.push(source);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v : adj[u]) {
            if (dist[v] != -1) continue;
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }
    return dist;
}
```

假定邻接表中的顶点编号都合法。`dist == -1` 表示未访问或不可达。入队时就标记，能避免同一顶点被重复加入。

BFS 给出无权图或所有边权相同的图中，以边数计的最短路。若要恢复路径，首次访问时再记录前驱。遍历整个非连通图，需要对所有未访问顶点分别启动搜索。

### 3. 最短路径

| 算法              | 适用条件                                       | 典型复杂度                      |
| ----------------- | ---------------------------------------------- | ------------------------------- |
| BFS               | 无权或等权边                                   | $O(V+E)$                        |
| Dijkstra          | 所有边权非负                                   | 矩阵朴素实现 $O(V^2)$           |
| Dijkstra + 二叉堆 | 所有边权非负                                   | 支持降键的实现 $O((V+E)\log V)$ |
| Bellman–Ford      | 可含负边，可检测源点可达负环                   | $O(VE)$                         |
| Floyd–Warshall    | 全源最短路，可含负边；有限最短路要求无相关负环 | $O(V^3)$，空间 $O(V^2)$         |

常见 `priority_queue` 版本的 Dijkstra 不真正降键，而是把新距离再次入堆，出堆时跳过过期条目。一般可按 $O((V+E)\log(V+E))$ 估计；对普通简单图通常写作 $O((V+E)\log V)$。

松弛操作：

$$
d[v]\gets\min(d[v],d[u]+w(u,v)).
$$

Dijkstra 每次确定当前距离最小的未确定顶点。非负权条件使这个距离以后不会再被更短路径推翻；存在负边时这一依据就不成立。

Bellman–Ford 在最多 $V-1$ 轮全面松弛后，若仍能从源点可达的有限距离继续改进，则存在源点可达负环。能由该负环继续到达的顶点，不存在有限的最短距离。

Floyd 的状态转移：

$$
d[i][j]=\min(d[i][j],d[i][k]+d[k][j]).
$$

允许作为中转点的编号 $k$ 必须放最外层。初始化时对角线通常置零，多重边取最小权值；相加前判断两段可达，避免无穷大哨兵值相加溢出。若有负权自环，应保留它对对角线的负值影响。

### 4. 最小生成树

最小生成树针对连通无向带权图，连接所有顶点，包含 $V-1$ 条边，并使总边权最小。它不保证任意两点沿树上的路径都是原图最短路。

- Prim：从已选顶点集合出发，每次选跨越当前割的最轻边。
- Kruskal：按边权从小到大选边，若加入会成环就跳过；通常用并查集判断连通性。

Prim 的邻接矩阵版本为 $O(V^2)$。Kruskal 的主要开销为边排序，通常写 $O(E\log E)$，另需考虑顶点初始化成本。负边权不会破坏这两个算法。

图不连通时得到最小生成森林。边权有重复时最小生成树可能不唯一；边权全部不同是唯一性的充分条件。

### 5. 拓扑排序与关键路径

拓扑序要求有向图每条边 $u\to v$ 中，$u$ 都排在 $v$ 前面。有拓扑序当且仅当图无有向环。

Kahn 算法：先将所有入度为零的顶点入队，取出后删除其出边；邻居入度降为零时入队。若最终输出顶点数小于 $V$，说明有环。时间 $O(V+E)$。

AOE 网以边表示活动、边权表示工期，顶点表示事件，需是有向无环图。事件最早发生时间沿拓扑序取最大值：

$$
ve[v]=\max_{u\to v}\{ve[u]+w(u,v)\}.
$$

事件最迟发生时间沿逆拓扑序取最小值：

$$
vl[u]=\min_{u\to v}\{vl[v]-w(u,v)\}.
$$

对活动 $u\to v$，最早开始时间为 $ve[u]$，最迟开始时间为 $vl[v]-w(u,v)$，两者之差为时差。零时差活动为关键活动。

多源、多汇时可增加零工期边连接的虚拟源点和汇点。关键路径可能不止一条；缩短某条关键路径上的活动，不一定立刻缩短整个项目工期。

## 七、查找、散列与并查集

### 1. 二分查找

二分查找依赖有序性。下面返回有序数组中第一个不小于 `target` 的位置；若不存在则返回 `a.size()`。

```cpp
std::size_t lower_bound_index(const std::vector<int>& a, int target) {
    std::size_t l = 0, r = a.size(); // 搜索区间 [l, r)
    while (l < r) {
        std::size_t mid = l + (r - l) / 2;
        if (a[mid] < target) l = mid + 1;
        else r = mid;
    }
    return l;
}
```

不变量：`l` 之前的元素都小于目标，`r` 及之后的元素都不小于目标。区间缩到空时，分界点就是答案。

要判断是否存在目标，还应检查返回值未越界且对应元素等于目标。不要直接访问 `a[a.size()]`。

时间 $O(\log n)$，额外空间 $O(1)$。在链表上找到中点需要遍历，所以不能直接获得数组二分的随机访问优势。

### 2. 散列表

散列函数把关键字映射到桶。不同关键字映射到同一位置称为冲突，实际使用中必须处理。

装填因子 $\alpha=n/m$，其中 $n$ 为元素数，$m$ 为桶数或槽位数。

- 拉链法：同一桶的元素另用链表或其他结构存放。均匀散列等假设下，查找期望开销约为 $O(1+\alpha)$。
- 开放定址法：冲突后继续探测其他空槽，例如线性探测、二次探测、双重散列。

保持适当装填因子且散列分布良好时，插入和查找通常期望为 $O(1)$；严重冲突时可能退化为 $O(n)$。扩容还涉及重新散列，不能声称每次操作最坏都是常数时间。

开放定址法删除时通常要留“已删除”标记。若直接把槽位置空，查找后续冲突元素时可能过早停止。

### 3. 并查集

并查集维护集合划分，支持查找某元素所属集合和合并两个集合。适合动态连通性、Kruskal 判环，不直接支持高效拆分集合。

```cpp
struct DSU {
    std::vector<int> parent, size;

    explicit DSU(int n) : parent(n), size(n, 1) {
        std::iota(parent.begin(), parent.end(), 0);
    }

    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b) return false;
        if (size[a] < size[b]) std::swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};
```

假定构造时 $n\ge0$、传入下标合法。路径压缩配合按大小合并后，每次操作的均摊复杂度为 $O(\alpha(n))$，其中 $\alpha$ 是反阿克曼函数，实际规模下增长极慢，但严格说不等于最坏 $O(1)$。

## 八、排序

### 1. 稳定性

若两个记录关键字相同，排序后仍保留它们原来的相对顺序，则排序稳定。例如先按姓名排列，再用稳定排序按成绩排列，同分者仍保持姓名顺序。

稳定性针对完整记录的相对顺序，只有整数数值时不容易直接观察。

### 2. 常见排序对照

下表针对数组上的常见实现；“空间”指辅助空间，并计入递归栈。

| 算法             | 最好时间     | 平均时间     | 最坏时间     | 辅助空间                              | 稳定性           |
| ---------------- | ------------ | ------------ | ------------ | ------------------------------------- | ---------------- |
| 直接插入         | $O(n)$       | $O(n^2)$     | $O(n^2)$     | $O(1)$                                | 可稳定           |
| 冒泡，带提前退出 | $O(n)$       | $O(n^2)$     | $O(n^2)$     | $O(1)$                                | 可稳定           |
| 简单选择         | $O(n^2)$     | $O(n^2)$     | $O(n^2)$     | $O(1)$                                | 通常不稳定       |
| 希尔             | 依增量序列   | 依增量序列   | 依增量序列   | $O(1)$                                | 不稳定           |
| 快速             | $O(n\log n)$ | $O(n\log n)$ | $O(n^2)$     | 常规递归平均 $O(\log n)$，最坏 $O(n)$ | 不稳定           |
| 归并             | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(n)$                                | 可稳定           |
| 堆排序           | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(1)$                                | 不稳定           |
| 计数             | $O(n+K)$     | $O(n+K)$     | $O(n+K)$     | 稳定记录排序通常 $O(n+K)$             | 可稳定           |
| LSD 基数         | $O(d(n+b))$  | 同左         | 同左         | $O(n+b)$                              | 每趟稳定时可稳定 |

$K$ 为整数关键字范围大小，$d$ 为位数，$b$ 为每一位的取值数。快速排序的平均复杂度依赖随机输入或随机化等假设。表中的堆排序给出常用渐近上界，具体输入与下沉实现可能影响最好情况。

### 3. 几种排序的关键操作

插入排序维护左侧有序区，把当前元素向左插入。移动条件使用 `>` 而非 `>=`，可以避免相同关键字互相越过。数据规模小或基本有序时常有较好表现。

选择排序每次选择未排序区最小值与首元素交换。即使输入已经有序，仍需大量比较。一次远距离交换可能打乱相同关键字的相对顺序。

快速排序先选枢轴并划分，再递归处理两边。枢轴总落在极端位置时退化为平方时间；随机选枢轴可以降低这种坏情况的出现概率，但不改变理论最坏上界。重复关键字很多时，三路划分往往更合适。

归并排序先分别排好左右两半，再线性合并。相等时优先取左边元素，可保持稳定。

```cpp
// 将 a[l..r) 排序；buffer 必须至少与 a 等长，且不能与 a 为同一对象。
void merge_sort(std::vector<int>& a, std::vector<int>& buffer,
                int l, int r) {
    if (r - l <= 1) return;
    int m = l + (r - l) / 2;
    merge_sort(a, buffer, l, m);
    merge_sort(a, buffer, m, r);

    int i = l, j = m, k = l;
    while (i < m && j < r) {
        if (a[i] <= a[j]) buffer[k++] = a[i++];
        else buffer[k++] = a[j++];
    }
    while (i < m) buffer[k++] = a[i++];
    while (j < r) buffer[k++] = a[j++];
    for (int t = l; t < r; ++t) a[t] = buffer[t];
}
```

调用前准备等长辅助数组，并传入合法区间 `[0, n)`。这里沿用 `int` 下标，要求数组长度不超过其可表示范围。

堆排序先建大根堆，再反复把堆顶最大值交换到当前末尾，对剩余前缀恢复堆结构，最终得到升序数组。

### 4. 排序的选择

- 少量数据或基本有序：可考虑插入排序。
- 要求稳定且能接受额外数组：归并排序适合。
- 原地处理且希望最坏时间有 $O(n\log n)$ 保证：堆排序是常见选择。
- 普通内存排序追求平均效率：快速排序及其改进常用。
- 整数取值范围小：考虑计数排序；范围过大会浪费空间。
- 数据无法全部放进内存：外部排序关注磁盘读写次数，常采用多路归并。

基于比较的通用排序，在最坏情况下需要 $\Omega(n\log n)$ 次比较。计数、基数排序利用了关键字范围或位结构，所以不受同一比较模型下界的直接限制。

## 九、扩展：B 树、B+ 树与索引

B 树和 B+ 树都是多路平衡查找结构，重点是减少访问层数。数据库和文件系统的索引需要考虑一次磁盘页读取能带来多少关键字，不能只比较单次 CPU 操作。

常见约定中，$m$ 阶 B 树的节点最多有 $m$ 个孩子、$m-1$ 个关键字，非根内部节点至少有 $\lceil m/2\rceil$ 个孩子；根节点有单独规定。不同教材对“阶”的定义可能不同，解题时先看题目约定。

典型 B+ 树把数据记录或记录指针集中在叶子，内部节点用于索引，叶子之间有顺序链接，因此范围查询可以先定位起点，再沿叶子依次扫描。B 树的内部节点也可以存记录。

## 十、综合题的检查顺序

拿到题目先看数据规模、数据是否有序、是否允许重复、操作是一次还是反复执行。再确定结构和不变量，最后写代码。

常见边界：

- 空表、单节点、数组只有一个元素。
- 目标不存在，或者重复出现多次。
- 链表删首节点、删尾节点、全部删空。
- 图不连通、有自环、重边、负边或负环。
- 树退化为链，递归深度超过预期。
- 整数相加或中点计算溢出。
